Analyzer and editor connection

Analyzer ready means the bridge’s language server is running and ready. It does not mean your code passed a compiler check.

Companion connected means Zed can send open files and unsaved edits to the bridge. Without it, the bridge watches saved files on disk.

Saved-file checks always use disk contents. Live diagnostics can use unsaved buffers when the companion is connected; coverage depends on the language server.

Connect Zed

  1. Install the Editor LSP Bridge extension in Zed.
  2. Enable it alongside the existing language servers in Zed settings. Merge this into each language you use:
"Rust": {
  "language_servers": ["...", "editor-lsp-bridge"]
}

The same setting applies to TypeScript, TSX and JavaScript. Installing the extension makes the companion available; enabling it tells Zed to start it.

Open a supported file in your workspace and restart language servers. The companion connects automatically. If it does not, check the extension’s executable path and Zed’s language-server logs.
